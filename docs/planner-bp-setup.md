# 血压记录

进入第五个“体重”页，使用内部“体重 / 血压”切换。在“血压”下点击“记录血压”，填写测量日期时间、高压（收缩压，mmHg）、低压（舒张压，mmHg），可选填心率（次/分）和备注。

- 一天可添加多次，也允许同一时刻的多条独立测量。只修改或删除选中的那一条，不覆盖当天其他记录。
- 日期时间固定按 UTC+8 输入和显示，数据库保存 timestamptz。支持秒精度，不能填写未来时间。体重仍按每天一条独立保存。
- 高压、低压与心率使用整数，输入技术范围 1–999；高压必须大于低压，心率可留空。技术校验不代表健康值范围，页面只展示记录，不做医学分类。
- 高压、低压使用两条不同颜色的曲线、同一 mmHg 纵轴，横轴保留实际测量时间间隔。漏记日期不补零；跨越漏记日用虚线连接。同一天多次测量按实际时间展开。
- 可查看近 30 天、近 90 天、指定月份、全部；搜索日期、测量值或备注。点击圆点或列表“修改”编辑，键盘选中圆点后 Enter 也可编辑。
- 最近血压卡片使用最近一条记录；心率只取同一条测量，留空时显示“—”，不沿用其他记录。
- 列表先显示 20 条，可继续加载。所有数据分页读取，不受 API 默认返回条数上限影响。版本 6 JSON 备份的 `blood_pressure` 包含全部历史。

## 部署

在已有基础日程数据库上执行一次 `supabase/migrations/20261017214530_planner_blood_pressure.sql`，然后发布网页，无需新增服务或密钥。

表 `planner_blood_pressure` 的 RLS 限制每个用户只能读写自己的记录。owner/time 索引覆盖用户外键及时间查询；整数与时间约束由数据库复核。每次修改和删除使用 `updated_at` 条件防止静默覆盖其他设备的修改。用户删除时级联清除其测量。加入现有 Realtime publication，并沿用轮询、聚焦刷新及离线写入保护。
