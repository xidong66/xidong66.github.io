# 体重管理

第五个“体重”页签按日期记录测量值。统一单位 kg，最多两位小数，每个账号每天保留一条，可以漏记，不需要建立连续记录。

- 点击“记录体重”，默认今天；今天已有记录时直接显示原值以便修改。
- 选择过去日期可以补记。选择已有记录的日期会加载那天的值和备注，修改它不会移动或覆盖其他日期。测量日期按 UTC+8 计算，不接受未来日期。
- 可修改测量值、备注或确认删除。删除后重新计算统计与曲线，不生成 0 kg 或补值。
- 最新体重和“较上次测量”比较全部历史中最近的两次实际测量，不要求连续两天都有记录。
- 所选范围变化比较范围内最早、最晚的实际测量。只有一条或没有记录时显示“—”。搜索会筛选范围内的曲线和列表，最新体重卡片仍显示全部历史中最近的实际测量。
- 曲线横轴使用真实日历间隔，纵轴显示 kg。圆点表示实际记录；相邻日的测量用实线连接，间隔超过一天用虚线连接。空白日期不补零、不插值，不将未测量值当成实际数据。单次测量只显示一个点。
- 可切换近 30 天、近 90 天、指定月份、全部历史。点击圆点，或用键盘选中后按 Enter，可编辑对应日期。
- 流水列表先显示 20 条，可继续加载。数据库每批读取 500 条，长期记录和完整备份不会受单次 API 返回上限截断。
- 导出备份格式版本 5 的 `weight` 字段包含全部月份记录。网页不提供导入，恢复需要维护者处理。

## 部署

在已有基础日程数据库上执行一次 `supabase/migrations/20261017213143_planner_weight_records.sql`，然后发布网页，无需额外服务、图表库或密钥。

表 `planner_weight_records` 开启 RLS，仅登录用户可操作自己的测量。`unique(user_id,record_date)` 保证每日唯一，也为用户与日期过滤提供索引。体重以 0.01 kg 为整数单位保存，允许输入范围为 0.01–999.99 kg（输入技术范围，不代表健康建议）。数据库验证日期和值范围，用户删除时级联删除其记录。修改与删除使用 `updated_at` 条件，拒绝覆盖其他设备的更新。

沿用现有 Realtime、可见页面每 30 秒同步、聚焦同步及手动刷新。离线不写入，同步失败保留上次显示的测量并给出提示。
