# 项目管理

第六个主标签“项目”记录项目名称、状态、合作者、产出、问题反思、有趣发现及备注。合作者字段仅记录姓名，不赋予访问权限。

状态包括待启动、计划中、进行中、已完成、失败、已归档。默认保留原始顺序，支持按进行中优先、最近更新或名称排序；搜索覆盖所有字段。电脑以表格展示，手机以卡片展示；点击任意单元格或手机卡片字段直接编辑，离开该格自动保存。状态选择后立即保存；Enter 保存名称，Ctrl/Cmd+Enter 保存多行内容，Escape 取消。每行与手机卡片均有明确的“编辑”按钮，可打开完整表单编辑备注或删除。支持新增、编辑、删除及跨设备同步。

部署前运行 `supabase/migrations/20261025094908_planner_projects.sql`。迁移仅创建表、约束、索引、触发器、RLS 策略和实时订阅，不含任何个人项目内容。截图资料通过管理连接单独导入指定账号，不能放入公开静态文件或通用迁移。`source_key` 与 `user_id` 组合唯一，可用于防止重复导入，不以项目名称合并记录。

`planner_projects` 的四种操作仅对所属账号开放；匿名用户无访问权限。编辑及删除以 `id` 和 `updated_at` 为条件，拒绝过期版本；保存失败不清空表单。主备份格式版本 7 新增 `projects` 数组，包含全部项目，不受界面筛选和分页限制。退出登录会清除已渲染的项目及表单。

验证：`node --test tools/planner-projects.test.mjs`；另需验证数据库的账号隔离、输入约束、条件写入及手机表格/卡片切换。

单元格编辑只写入当前字段，使用打开编辑器时的 updated_at 进行版本检查。后台同步不替换正在编辑的元素；失败时保留草稿并提示重试，冲突后需要取消并重新打开以避免覆盖另一设备的修改。
